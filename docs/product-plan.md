# Product Plan

## MVP

The MVP is student-first and web-first.

1. Demo mode without login
2. Account registration and login
3. Subject, term, and grade management
4. Weighted averages and rounded semester grades
5. Required grade calculator
6. BMS calculator with diagnostics
7. EFZ calculator with diagnostics
8. CSV import/export
9. Responsive, clear UI

## Later

- Teacher accounts
- Classes
- Invite codes
- Teacher-to-student shared grades
- PDF reports
- Excel import
- Advanced analytics
- Native/PWA wrappers

## Product Principles

- Correct calculations beat flashy UI.
- Demo mode must feel useful immediately.
- Account mode must protect every user-owned resource.
- Teacher features wait until the student workflow is stable.
